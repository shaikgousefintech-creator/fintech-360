# FINTECH 360° - Digital Gold Data Quality

## 1. Overview

The Digital Gold module implements data quality validation at multiple stages to ensure that customer, gold price, transaction and wallet ledger data is accurate, complete and consistent.

Validation is performed across:

- Raw source datasets.
- SQLite analytical data marts.
- Python analytics outputs.
- Business insights outputs.

The validation framework uses Python, Pandas and SQL queries to identify data inconsistencies and verify financial and gold quantity calculations.

## 2. Raw Data Quality Validation

**Script:** `src/quality/digital_gold_quality_checks.py`

**Input directory:**

`data/raw/digital_gold/`

The raw data validation covers four datasets:

| Dataset | Purpose |
|---|---|
| `digital_gold_customers.csv` | Customer information |
| `digital_gold_price_history.csv` | Historical gold prices |
| `digital_gold_transactions.csv` | Gold purchase and sell transactions |
| `digital_gold_wallet_ledger.csv` | Customer wallet ledger records |

**Validation categories:**

| Category | Validation |
|---|---|
| Schema | Required columns and expected structure |
| Primary Keys | Unique customer, price, transaction and ledger identifiers |
| Required Values | Missing or null mandatory fields |
| Numeric Values | Valid numeric and financial values |
| Foreign Keys | Valid customer and transaction relationships |
| Business Rules | Valid transaction types and business constraints |
| Failure Reasons | Failure reason consistency for unsuccessful transactions |
| Dates | Valid dates and chronological consistency |
| Price Uniqueness | Duplicate gold price records |
| Transaction-Price Consistency | Transaction prices against historical price records |
| Financial Calculations | Transaction amount and gold quantity consistency |
| Wallet Ledger | Ledger entry consistency |
| Holdings | Gold purchase and sell quantity calculations |
| Wallet Balances | Running wallet balance consistency |

## 6. Financial and Gold Quantity Validation

Digital Gold transactions involve buying and selling gold quantities at applicable transaction prices.

The project validates:

- Gold quantity and transaction amount consistency.
- Historical price consistency.
- Successful BUY and SELL quantities.
- Wallet ledger entries.
- Running wallet balances.
- Customer-level gold holdings.

**Net Gold Quantity:**

`Net Gold Quantity = Successful BUY Quantity - Successful SELL Quantity`

For the current synthetic dataset:

| Metric | Quantity |
|---|---:|
| Successful BUY quantity | 191,069.8864 g |
| Successful SELL quantity | 52,669.8025 g |
| Net gold quantity | 138,400.0839 g |

Net gold quantity represents the difference between successful purchase and sell quantities. It is not a monetary portfolio valuation or investment return.
