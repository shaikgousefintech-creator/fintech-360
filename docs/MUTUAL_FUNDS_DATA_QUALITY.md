# FINTECH 360° - Mutual Funds Data Quality

## 1. Overview

The Mutual Funds module implements data quality validation at multiple stages to ensure that investor, scheme, NAV and investment transaction data is accurate, complete and consistent.

Validation is performed across:

- Raw source datasets.
- SQLite analytical data marts.
- Python analytics outputs.
- Business insights outputs.

The validation framework uses Python, Pandas and SQL queries to identify data inconsistencies and verify financial calculations.

## 2. Raw Data Quality Validation

**Script:** `src/quality/mutual_fund_quality_checks.py`

**Input directory:**

`data/raw/mutual_funds/`

The raw data validation covers four datasets:

| Dataset | Purpose |
|---|---|
| `mutual_fund_investors.csv` | Investor information |
| `mutual_fund_schemes.csv` | Mutual fund scheme details |
| `mutual_fund_nav_history.csv` | Historical scheme NAV values |
| `mutual_fund_transactions.csv` | Investment purchase and redemption transactions |

**Validation categories:**

| Category | Validation |
|---|---|
| Schema | Required columns and expected structure |
| Primary Keys | Unique investor, scheme, NAV and transaction identifiers |
| Required Values | Missing or null mandatory fields |
| Numeric Values | Valid numeric and financial values |
| Foreign Keys | Valid relationships between investors, schemes and transactions |
| Business Rules | Valid transaction types and business constraints |
| Failure Reasons | Failure reason consistency for unsuccessful transactions |
| Dates | Valid dates and chronological consistency |
| NAV Uniqueness | Duplicate NAV records |
| Transaction-NAV Consistency | Transaction pricing against NAV history |
| Financial Calculations | Investment amount and units consistency |
| Holdings | Investor holding calculations and transaction consistency |

**Recorded result:** 39/39 checks passed.

## 6. Financial Data Validation Considerations

Mutual Funds transactions involve investment purchases and redemptions.

The project validates the financial relationship between transaction amounts, NAV values and units.

**Net Investment:**

Net investment is calculated using successful investment transactions:

`Net Investment = Successful Purchase Amount - Successful Redemption Amount`

This represents net investment flow, not investment return or portfolio valuation.

The project does not treat transaction volume or net investment flow as actual assets under management (AUM).
